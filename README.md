# 基于 SpringBoot + Vue  的旅游景区系统

民宿预订 · 景点导览 · 社区论坛 · 订单管理 | 面向超级管理员、民宿管理员与游客的一站式智慧旅游服务平台

本项目是一套基于 **Spring Boot + Vue** 的旅游景区系统，采用前后端分离架构，覆盖 **超级管理员、民宿管理员、用户（游客）** 三类核心角色。系统围绕"景点/民宿资源整合 → 民宿在线预订 → 订单支付 → 评价互动 → 社区论坛 → 消息沟通 → 数据统计"的完整旅游服务闭环设计，打通从游览到住宿的全流程，构建高效便捷的智慧旅游平台。

## 核心特性

- **景点民宿一体化导航**：超级管理员统一维护景区景点与民宿资源，用户可按地理位置、价格区间、评分等多维度检索，实现"游+住"一站式服务。
- **民宿在线预订与房态管理**：民宿管理员实时管理房间库存与入住状态，用户在线选择入住/离店日期完成预订，系统自动校验房态冲突。
- **订单支付与评价闭环**：用户完成订单支付后查看支付结果，入住后可对民宿/景点进行星级评分与图文评价，形成服务反馈闭环。
- **社区论坛互动**：内置旅游论坛模块，用户可发帖分享游记、回复他人帖子，管理员进行内容审核，构建活跃的旅行社区氛围。
- **多维数据统计**：民宿管理员端提供订单数量统计、订单交易额统计、客房统计饼图等可视化图表，辅助经营决策。
- **消息实时沟通**：集成消息系统，支持管理员回复用户咨询、用户与民宿管理员在线沟通，消息实时推送。

## 功能模块概览

## 超级管理员端

超级管理员为平台运营中枢，负责全局管控：

### 基础运营

- **景点民宿导航**：统一维护景区景点与民宿的关联关系，配置首页推荐位、轮播图、热门路线导航，打造"游+住"一体化入口。
- **公告管理**：发布平台公告，包括景区活动通知、民宿优惠信息、系统维护公告等，支持公告置顶与多端推送。
- **消息回复**：查看并回复用户提交的咨询消息、投诉建议，管理全平台消息记录。

### 资源管理

- **景点管理**：管理景区景点信息，包括景点名称、地理位置（经纬度）、开放时间、门票价格、景点介绍、图片轮播、状态（开放/关闭），支持景点分类与标签管理。
- **民宿管理**：管理全平台入驻民宿，包括民宿名称、位置、联系人、联系电话、设施标签、资质审核状态，支持民宿上下架与违规处理。
- **房间信息**：查看全平台民宿房间信息，包括房型、价格、床型、最大入住人数、房间图片、当前状态（可入住/已预订/维修中）。

### 订单与评价

- **民宿订单**：查看全平台民宿订单，包括订单号、预订用户、民宿名称、入住/离店日期、订单金额、支付状态、订单状态，支持订单干预与退款处理。
- **景区订单**：查看景区门票/服务订单，包括订单号、预订用户、景点名称、购票数量、订单金额、核销状态。
- **订单评价**：管理全平台订单评价，查看用户提交的星级评分与图文评价，支持违规评价屏蔽与评价回复。

### 用户与社区

- **用户管理**：管理注册用户，包括用户姓名、手机号、邮箱、注册时间、账户状态，支持账户冻结/解冻。
- **论坛管理**：管理社区论坛内容，包括帖子审核、违规帖子删除、帖子置顶/加精、论坛板块管理。

## 民宿管理员端

民宿管理员（房东/民宿运营人员）通过 Web 端管理民宿日常运营：

### 数据统计

- **订单数量统计**：通过柱状图/折线图展示每日/每周/每月订单数量趋势，直观了解民宿预订热度。
- **订单交易额统计**：通过折线图展示订单交易额变化趋势，支持按时间段筛选，辅助营收分析。
- **客房统计饼图**：通过饼图展示当前房间状态分布（可入住/已预订/维修中/清洁中），一目了然掌握房态。

### 民宿与房间管理

- **酒店信息修改**：维护民宿基本信息，包括民宿名称、位置描述、联系电话、设施列表（WiFi/空调/独立卫浴等）、民宿介绍、Logo/图片上传。
- **酒店房间管理**：管理民宿房间，包括房型、价格、床型、最大入住人数、房间图片、房间状态，支持房间增删改查与批量房态更新。

### 订单处理

- **房间订单查询**：查询本民宿的所有订单，支持按订单状态（待支付/已确认/入住中/已完成/已取消）、入住日期等条件筛选。
- **查看住宿订单详情**：查看订单详细信息，包括预订用户信息、入住/离店日期、订单金额、支付状态、特殊需求备注。
- **房间入住状态修改**：手动更新房间入住状态（如标记为"已入住""已退房""清洁中""可入住"），实时同步房态。

### 评价与沟通

- **查看用户房间订单评价**：查看用户对本民宿订单的星级评分与图文评价，了解服务反馈。
- **消息回复**：回复用户发送的咨询消息，解答入住疑问、确认预订细节等。

## 用户端（游客）

用户通过 Web 端/移动端浏览景点、预订民宿、参与社区互动：

### 账户与个人

- **邮箱注册**：通过邮箱完成用户注册，填写用户名、邮箱、密码等基本信息，支持邮箱验证。
- **修改个人信息**：维护个人基本信息，包括昵称、头像、手机号、个人简介等。
- **修改密码**：修改账户密码，保障账户安全。

### 预订与支付

- **订单支付**：浏览景点与民宿后提交预订订单，选择支付方式完成在线支付（支持支付宝/微信/模拟支付），实时查看支付结果。
- **订单评价**：入住/游览完成后对民宿或景点进行星级评分与图文评价，分享真实体验。

### 社区互动

- **我的贴子**：查看个人发布的所有论坛帖子，包括帖子状态（审核中/已发布）、回复数、浏览量，支持帖子编辑与删除。
- **发帖回复**：在论坛发布新帖子（分享游记、提问求助等），回复他人帖子参与讨论，构建活跃的旅行社区。

### 消息管理

- **消息管理**：查看系统消息（订单状态变更/支付结果/审核通知）与管理员/民宿管理员发送的消息，支持消息标记已读与删除。
